# Steam screenshots

Nine 1920×1080 shots for the store page, in upload order: action first, then
the Command Center, skin select and campaign map. Gameplay is level 18
(Unknown Space) in the three skins with redrawn per-zone backgrounds —
Kiran (2026), Arcade Formation (1981), Neon Grid (2003).

Captured from the macOS desktop build of 3.8.6 in a frameless 1440×810 pt
window (2880×1620 px on Retina), corners cropped for the window's rounded
mask, then scaled to 1920×1080. The capture build was invulnerable, kept
firing and cycled the loadout through all five weapon families every 8 s;
those edits and the driver were local to a worktree and never committed.
The app's language was forced to English for the run (`defaults write
com.ol1n.tyrianMobile AppleLanguages -array en`, deleted afterwards).
