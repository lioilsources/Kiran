# What's New — 2.10.0 (App Store + Google Play)

Production before this release was 2.9.2, so the notes cover everything since:
the loadout-first Command Center and its per-skin backgrounds (2.9.4), the UI
in 15 languages (2.9.3) and the new app icon (2.10.0). Command Center first,
icon last — everyone sees the icon anyway. Terms follow the game's own ARB
(`commandCenter`, `sectionLoadout`, `skins`).

en-AU, en-CA and en-GB take `en`; es-MX takes `es`.
